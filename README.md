# MNAI Application

Windows installer for **MNAI** — the AI chat app by MeowSamOPDZN Studio.

## Download

Get the latest installer from [Releases](../../releases) — `MNAI-Setup-1.0.0.exe` (about 158 MB).

## Install

1. Download `MNAI-Setup-1.0.0.exe` from Releases.
2. Run it. It needs administrator permission.
3. MNAI installs to `C:\Program Files\MNAI` (you can change this during setup), with Start Menu and desktop shortcuts and an uninstaller.

Note: the installer is unsigned, so Windows SmartScreen will warn you. Click **More info**, then **Run anyway**.

## Requirements

- Windows 10 or 11, 64-bit
- An internet connection — the app loads the live MNAI site, so it is always up to date

## Uninstall

Use Windows Settings → Apps, or the uninstaller in the Start Menu folder. It removes the app files, shortcuts, and the Add/Remove Programs entry.

## Web version

MNAI also runs in the browser at https://mnaii.vercel.app/
